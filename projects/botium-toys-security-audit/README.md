# Botium Toys — Internal Security Audit

## Project Overview

This project involved conducting a simulated internal security audit of Botium Toys as part of the Google Cybersecurity Professional Certificate.

The assessment was used to evaluate the organisation's existing security controls, identify security weaknesses, consider relevant compliance requirements, and recommend improvements to reduce security risks.

## Objectives

- Assess the organisation's existing security controls
- Identify gaps in its security posture
- Evaluate relevant compliance requirements
- Identify risks to sensitive customer information
- Recommend appropriate security improvements

## Security Controls Assessed

The assessment considered a range of technical, administrative, and physical security controls, including:

- Least privilege
- Password policies
- Disaster recovery plans
- Separation of duties
- Firewall
- Intrusion detection system (IDS)
- Backups
- Antivirus software
- Encryption
- Password management
- Physical security
- CCTV surveillance
- Fire detection and prevention

## Compliance Assessment

The assessment considered security and compliance requirements relating to:

### PCI DSS

The assessment considered controls relating to the protection of customers' payment card information, including access restrictions, secure handling of card data, encryption, and password management.

### GDPR

The assessment considered the protection of customer data, data classification and inventory, privacy policies, and procedures for responding to data breaches.

### SOC Controls

The assessment considered controls relating to user access, confidentiality, data integrity, and availability.

## Key Findings

The assessment identified several significant security weaknesses.

### Lack of Access Controls

The organisation did not have appropriate access controls in place, increasing the risk of unauthorised access to systems and sensitive information.

### Unencrypted Credit Card Data

Credit card information was not adequately protected through encryption, creating significant confidentiality and compliance risks.

### No Intrusion Detection

The organisation did not have an intrusion detection system in place, reducing its ability to identify potentially malicious activity.

### Weak Password Practices

Weak password practices increased the risk of compromised credentials and unauthorised access.

## Recommendations

The assessment recommended that Botium Toys prioritise the implementation of:

1. Appropriate access controls and least-privilege principles
2. Encryption for sensitive customer and payment information
3. Intrusion detection capabilities
4. Stronger password policies and password management
5. Improved security monitoring and incident response
6. Appropriate data protection and privacy procedures
7. Regular reviews of security controls and compliance requirements
